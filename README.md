## 📖 About The Project

**SkyCast** is a real-time weather web application that allows users to search for weather information for cities around the world. It can also detect the user's current location and display local weather automatically.

The application presents important weather information such as temperature, weather conditions, hourly updates, forecasts, and air quality in a clean and easy-to-use dashboard.

SkyCast is designed with a responsive interface that works smoothly across **mobile phones, tablets, and desktop screens**, with features such as favorite cities, temperature-unit switching, and dark/light mode for a better user experience.

---

## ✨ Key Features

- 🌍 Search weather for cities worldwide
- 📍 Automatic current-location detection
- 🌦️ Real-time weather conditions
- 🌡️ Temperature information
- 🕐 Hourly weather updates
- 📅 Weather forecast
- 🫁 Air-quality information
- ⭐ Favorite cities
- 🌡️ Celsius / Fahrenheit conversion
- 🌙 Dark / Light mode
- 📱 Fully responsive design
- ⚡ Dynamic weather icons and interface

## 🌦️ API

SkyCast uses the **OpenWeather API** to retrieve live weather information for locations around the world.

The application uses API data for:

- Current weather
- City/location search
- Weather forecasts
- Hourly weather information
- Air quality
